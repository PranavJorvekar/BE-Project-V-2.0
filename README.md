# AI SDLC Platform

An agentic orchestration layer for automating the Software Development Lifecycle. From product vision to engineering plan in seconds.

## 🚀 Quick Start

1. Ensure Node.js v18+ is installed.
2. Run `./start.bat` on Windows to launch both Backend and Frontend.
3. Access the dashboard at [http://localhost:3000](http://localhost:3000).

## 🛠 Features

- **Intelligent Requirements Parsing**: Translates raw text into structured PRDs.
- **Multi-Agent Pipeline**: Specialized agents for Epic generation, Task breakdown, and Team assignment.
- **Staffing Risk Detection**: Identifies bottlenecks and skill gaps automatically.
- **Premium Dashboard**: Modern, responsive UI for project orchestration.
